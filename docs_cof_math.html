01

CoF per sample

physics/CoF.py:9 turns the three raw force channels into one CoF value per sample. Which formula runs depends on the Normal Load Correction, λ:

λ not given→ μi = Li + RiWi
λ = 0→ μi = Li + Ri (flagged: not a true CoF, unitless force sum)
λ ≠ 0→ μi = Li + RiWi − λ , undefined (NaN) if Wi = λ

A row where λ overshoots Wi (i.e. Wi < λ) isn't rejected — it produces a sign-flipped μi silently.

μi ← round(μi, 5) — pipeline.py:52, immediately after the formula above. Every later stage reads this already-rounded value.
02

Offset & filter (optional)

Two independent, optional passes over μ — and they don't feed the same later stage. This is the detail most worth knowing: Filter never touches the CoF numbers that get reported.

Offset (toggle) → μi ← round(μi − mean(μ), 15)
utility_functions.py:40 — mean taken over the whole trimmed range. This result is what every later stage sees as “μ”.
Filter (form) → μ′i ← round(medianwindow w(μ), 15)
utility_functions.py:88 — a centered rolling median, window w samples wide. μ′ is used only to find zero-crossings (Stage 03) and decide stroke timing. Stage 05's static/dynamic CoF values are still read from μ, not μ′.
03

Zero crossings

utility_functions.py:98 Find_minima() walks μ′ (the filtered signal, or μ itself if Filter wasn't used) sample by sample and records every sign change — each one is a stroke reversal.

A crossing is recorded between samples i−1, i when both hold:
ti − ti−1 < 0.002 s (else the samples are too far apart to trust as one crossing)
μi−1 and μi differ in sign

The two straddling samples are labelled by sign — (t−, μ−) the one below zero, (t+, μ+) the one at or above it — and linearly interpolated to the instant μ actually crosses zero:

t0 = t+μ− − t−μ+μ− − μ+

A separate diagnostic (not shown here) flags any crossing spaced under 50% of the file's average crossing spacing as “noisy data” — it's a warning only, it doesn't exclude anything from the stages below.

04

One stroke, or a pause between steps?

Consecutive crossings only become one stroke if they're close enough together — otherwise the gap is assumed to be a pause between test steps and the pair is thrown out. The threshold used to decide that used to be a single fixed constant; it now adapts to each step's own speed when Drehzahl is supplied:

τpause(s) = max( 1.0 s ,  1.5 × 30ns )
30 / ns is step s's own expected half-stroke period, in seconds, from ns in rev/min. Falls back to the fixed 1.0 s alone when no Drehzahl is known for that step. utility_functions.py:228

A crossing pair at times tk−1, tk becomes a cycle only if tk − tk−1 ≤ τpause(s) — otherwise it's disregarded, no value produced.

Worked example
Drehzahl 120 rev/minhalf-period = 30/120 = 0.25 sτpause = max(1.0, 1.5×0.25) = 1.0 s — the fixed floor wins
Drehzahl 15 rev/minhalf-period = 30/15 = 2.0 sτpause = max(1.0, 1.5×2.0) = 3.0 s — the step's own period wins
05

Static & dynamic CoF, per cycle

utility_functions.py:183 Evaluate() — for a cycle spanning sample index idxk−1 to idxk (N = idxk − idxk−1 samples), three percentages from the Evaluate form set where in the stroke each value is measured:

a = Static % / 100   b = Dyn min % / 100   c = Dyn max % / 100

Every sample position below is rounded half up (VBA-style: round½(x) = ⌊x + 0.5⌋) — not Python's default banker's rounding:

end = idxk−1 + round½(a · N)
ds = idxk−1 + round½(b · N)
de = idxk−1 + round½(c · N)

Static CoF — the peak (or trough) of μ over samples [idxk−1, end], matching whichever direction the stroke moved:

μ*k = max[idxk−1,end](μ) if μend > 0,   min[idxk−1,end](μ) if μend < 0

Dynamic CoF — the mean of μ over the middle window [ds, de], n = number of samples in it:

μ̄k = 1nΣ[ds,de] μ
SDk = sample std. dev. (n−1 divisor) of μ over [ds,de]
σk = |μ̄k| · n  — a pool-ready “Σ|μ|”, carried forward to Stage 07
vk = SDk2(n−1) + σk2/n  — a pool-ready “Σμ²”, also carried forward
Worked example — defaults (Static 10%, Dyn 20–80%), stroke from sample 1000 to 1200 (N = 200)
end1000 + round½(0.10×200) = 1020static window: first 10% of the stroke
ds1000 + round½(0.20×200) = 1040dynamic window: the middle 60% of the stroke
de1000 + round½(0.80×200) = 1160

The code's own window is shifted two rows earlier than shown here (utility_functions.py:246) — a fixed legacy offset carried over byte-for-byte from the reference VBA workbook's row addressing, not a separate rounding rule.

06

The last stroke

A cycle needs two crossings — one to start it, one to close it. A recording almost never stops exactly on a reversal, so the final stroke has no closing crossing to pair with. Rather than drop it, it's closed against the last recorded sample instead, reusing Stage 05's formulas with one substitution:

idxk → last sample index of the recording

Its window is only as long as whatever data remains after the last crossing — shorter than a normal full stroke, since the real second reversal never happened before the recording ended. utility_functions.py:301

07

Per-step statistics

physics/statistics.py:5 CoF_Stat() — for step s spanning [Starts, Ends], gather every cycle k whose static-CoF time falls inside that window (count ns). Static and dynamic are combined two different ways:

Static — recomputed directly from each cycle's |μ*k| in the window:

X̄s = mean( |μ*k| , k ∈ s )    SDs = sample std. dev. of the same set
(X̄N)s = X̄s · ns    Vars = SDs2(ns−1) + (X̄N)s2/ns

Dynamic — pooled from each cycle's already-computed σk, vk (Stage 05) — never re-touches raw samples:

Ns = Σk∈s nk    (σN)s = Σk∈s σk    Vs = Σk∈s vk
Ās = (σN)sNs    SDs = Vs − (σN)s2/NsNs − 1

A step with zero surviving cycles in its window (Stage 04's threshold rejected all of them, or Stage 05 skipped them as degenerate) simply produces no row — not a zero, an absence.
